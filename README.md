# Recorrido Virtual Web ITACE

> Pagina web interactiva diseñada para realizar un recorrido por las diferentes instalaciones del plantel ITACE, asi como divulgar informacion oficial del plantel para un mejor acceso.

---

## Descripcion
Este proyecto es una plataforma web interactiva que guia a los usuarios a traves de un recorrido virtual por las instalaciones de ITACE. Permite explorar areas clave como zonas verdes, espacios deportivos, servicios de salud, control escolar y areas administrativas divididas en subsecciones de manera dinamica y accesible desde cualquier navegador, ademas puedes acceder a noticias, eventos, conferencias, logros, historia, proposito e informacion de contacto de ITACE a medida que vas navegando.

## Objetivo
Proporcionar una herramienta digital que facilite el conocimiento del plantel a estudiantes, padres de familia y personal administrativo, permitiendoles ubicar y conocer las funciones de cada area de la institucion sin necesidad de trasladarse fisicamente, y resolver dudas respecto a procesos de inscripcion o incluso poder ver con antelacion los procesos o eventos que se llevan a cabo en el plantel.

## Tecnologias utilizadas
* HTML5: Para la estructuracion de todas las paginas y secciones del recorrido.
* CSS (estilos itace.css): Para el diseño visual, maquetacion y presentacion del sitio web.
* JavaScript (itace script.js): Para la interactividad y comportamiento dinamico de pagina.

## Funcionalidades
* Menu de navegacion: Acceso directo a todas las secciones mediante el menu de navegacion superior desde la interfaz de itace principal.html.
* Secciones detalladas por zonas: Paginas especificas para areas verdes, canchas deportivas, cooperativa y prefectura.
* Modulos de servicios estudiantiles: Informacion integrada sobre enfermeria, vinculacion, control escolar y direccion.
* Secciones de eventos e informacion de inscripcion para el conocimiento de agentes externos a la institucion.
* Informacion de contacto del plantel para un mejor acceso y obtencion.
* Contenido multimedia: Integracion de carpetas dedicadas para reproducir audios, imagenes y videos de las instalaciones.

## Instrucciones para ejecutar el sitio
Para visualizar y navegar en el recorrido virtual de ITACE en la computadora local, sigue estos pasos:

1. Descarga o clona la carpeta completa del proyecto "pagina web itace recorrido".
2. Asegurate de mantener la estructura interna de las carpetas (audios, imagenes, videos) para que los archivos multimedia carguen correctamente.
3. Localiza el archivo index.html o itace principal.html en el directorio raiz.
4. Haz doble clic sobre el archivo index.html para abrirlo de forma automatica en tu navegador web actualizado.
